# steam-integration

A tool to search the Steam catalog for games. Officially supported by OpenGameInstaller.

## About this fork

This is ShockStruck's fork of [Nat3z/steam-integration](https://github.com/Nat3z/steam-integration). The original code and its authorship belong to the OGI Team; this fork carries fixes that have not yet landed upstream, and each one is also offered upstream.

Upstream ships no licence: there is no `LICENSE` file and no `license` field in `package.json`. This fork adds none and claims none. It exists under GitHub's terms of service for forking public repositories.
